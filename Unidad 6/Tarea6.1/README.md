## 📌 Descripción

Investigación exhaustiva y estructurada de las características del lenguaje SQL, su evolución formal, estándares internacionales (ANSI/ISO) e implementación sobre el motor relacional **Microsoft SQL Server (Transact-SQL)**. Se presenta una taxonomía analítica y comparativa de los sublenguajes:

1. **Lenguaje de Definición de Datos (LDD / DDL):** `CREATE`, `ALTER`, `DROP`, `TRUNCATE`.
2. **Lenguaje de Manipulación de Datos (LMD / DML):** `INSERT`, `UPDATE`, `DELETE`, `SELECT`.

Cada comando cuenta con su sintaxis formal BNF, parámetros técnicos, restricciones de integridad soportadas y opciones avanzadas de motor relacional ejemplificadas sobre el caso de estudio de la **Tienda de Abarrotes**.
